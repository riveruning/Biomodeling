# 与 BioModel Agent 相近的已发表系统

检索截至：2026-10-17。仅作讨论调研，不是产品开发指令。按功能接近程度选取代表性工作，非穷尽综述。文献中的成绩是作者报告，本次没有复测这些已发表系统。

## 单独对照表

| 系统与发表信息 | 输入及实际做的工作 | 论文中的验证方式 | 与我们的关系和需要注意的边界 |
|---|---|---|---|
| **Talk2Biomodels**；BMC Bioinformatics，2025 | 用自然语言检索 BioModels、导入 SBML，调用模拟、参数扫描、稳态、绘图、注释与论文 RAG 工具 | 多个 ODE 应用案例；两个合成问答集共 312 对问题/答案，结合 BASICO 输出与 DeepEval 任务完成评分 | **当前最直接相关的 Agent**。重点是使用已有可执行模型；文中明确初版不支持模型扩展，不能当成任意论文自动建模系统。[原论文](https://link.springer.com/article/10.1186/s12859-025-06310-1) |
| **KinModGPT**；International Journal of Molecular Sciences，2023 | GPT 把自然语言反应描述转为中间建模表达，再通过 Tellurium 生成 SBML 并模拟 | 代谢、蛋白互作和热激响应等模型描述；考察生成有效模型及模拟 | **与“文字→动力学模型”直接相关**。更接近 GPT＋工具转换流程，不应混称为现代自主 Agent；输入是模型描述，不等于任意论文端到端复现。[论文摘要](https://pubmed.ncbi.nlm.nih.gov/37108453/)、[作者代码](https://github.com/kmaeda16/KinModGPT) |
| **Paper2Agent**；Nature，2026 | 从论文及其代码库构建经过测试的 MCP 工具、资源和工作流，让外部聊天/编程 Agent 调用论文方法 | AlphaGenome、Scanpy、TISSUE 等案例及更大规模论文与查询评测；含 Claude Code＋代码库对照 | **与论文复用和可执行研究产物直接相关**。常依赖已有代码、数据与可配置环境；不能把“包装现有方法”与“仅从论文恢复未知方程”视为同一任务。[正式论文](https://www.nature.com/articles/s41586-026-11044-y)、[作者代码](https://github.com/jmiao24/Paper2Agent) |
| **Biomni**；Science，2026 | 检索规划结合代码执行，动态组合生物医学工具、数据库和协议，覆盖多种分析与实验相关任务 | 异构任务基准，包含因果基因优选、药物再利用、微生物组等；另有真实工作案例 | 是**广义生物科研助手的重要对照对象**；范围远大于 ODE 建模。已核验期刊发表信息与摘要，但本文概述不等于已审核其每一项全文实验。[正式论文 DOI](https://doi.org/10.1126/science.adz4351)、[PubMed](https://pubmed.ncbi.nlm.nih.gov/42424436/) |
| **CellVoyager**；Nature Methods，2026 | 在 Jupyter 环境自主提出并执行单细胞 RNA-seq 分析，形成探索性发现 | CellBench 基于 76 项已发表研究，另有三个深入案例及专家评价 | 接近“研究问题→分析执行→解释”的闭环；其数据分析与发现任务不是 ODE 参数或机制重建。此处依据出版社摘要与公开页面。[正式论文](https://www.nature.com/articles/s41592-026-03029-6) |
| **CellAtria**；npj Artificial Intelligence，2026 | 从论文抽取单细胞数据元信息、获取数据，再通过预验证工具调用 CellExpress 处理流程 | 文献到数据处理的案例及不同入口的数据获取/分析演示 | 对**文献→结构化信息→受控科学工具**的设计有参考意义；针对单细胞流程，不是动力学机制建模。[正式论文](https://www.nature.com/articles/s44387-025-00064-0) |
| **BioDiscoveryAgent**；ICLR，2025 | 结合生物知识、文献、代码分析与反思，迭代选择基因扰动实验，以寻找目标表型 | 六个扰动数据集的迭代实验选择评测，与贝叶斯优化等比较；含未公开数据集 | 与我们长期的**下一步实验建议**方向接近；主要评价扰动选择，不证明从论文生成 ODE 或发现唯一真实机制。[正式会议论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/4252dc94531833029000f85dc5fac792-Paper-Conference.pdf) |
| **Coscientist**；Nature，2023 | 结合文献与硬件文档检索、代码和实验设备，规划、执行并优化化学实验 | 六类任务及真实实验设备/反应优化案例 | 对**工具执行、反馈、实验闭环**有参考价值，但属于化学实验自动化，与生物 ODE 不是直接同任务竞争者。[正式论文](https://www.nature.com/articles/s41586-023-06792-0) |

## 从这些工作中得到的判断（我们的推断）

1. 自然语言操作 SBML、文字生成动力学模型、带执行能力的论文助手，都已有相关工作，不能单独当成我们的创新点。
2. 最值得优先仔细对照的是 Talk2Biomodels、KinModGPT、Paper2Agent：分别对应模型使用、文字转模型、论文方法复用。
3. 我们可能聚焦“来源约束下的模型重建、缺失信息协作、验证与复算”这一具体任务组合；它是否更可靠或更省人工，仍须直接实验。
4. “可追踪”“可复现”“有工具”本身不能默认优于已有系统，必须用相同任务衡量结果与人工工作量。

## 与本次小型实测的区别

本表是**文献功能调研**，没有运行这些已发表系统，也不构成性能排行榜。
本次实际小评测另存于 `artifacts/comparison-pilot-20261017/`，已完成 Codex、通用 DSH 和本项目 Agent 各三个输入条件，共九次运行。三者均通过信息完整条件的数值检查，未显示本项目在该小案例上的核心性能优势；完整结果见该目录的 report.md。
