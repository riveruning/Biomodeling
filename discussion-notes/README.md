# Agent 方向讨论区

这里保存我们围绕科研 Agent 后续方向的想法、问题和调研笔记。

## 与实际开发的边界

- 本目录是讨论资料，不是项目规范、开发计划、需求或验收标准。
- 内容可以包含猜想、不同意见、未验证判断和暂时放弃的方向，不代表已经作出决定。
- 不把这里的内容自动用于指导实现、安排任务、修改架构或派发 DSH 工作。
- 只有用户明确确认将某项讨论转为实际开发任务后，才在本目录之外另行记录正式要求；原讨论仍作为背景保留。
- 查看项目开发要求或推进开发时，不默认读取或引用本目录；仅在用户要求讨论、调研或查阅相关想法时使用。

本目录中的内容不影响现有代码、正式文档、任务卡或评测结论。

## 记录方式

每个话题单独保存为 Markdown 文件，建议命名为 `YYYY-MM-DD-话题.md`。
可以记录问题、备选方向、支持与反对的理由、调研来源及尚待验证的假设。
有外部资料时注明来源；区分资料中的结论和我们自己的推测。
