# T08c：共同 HTTP 传输与离线外发准备

Codex 独立实现，本轮不调用线上模型、不发送项目材料、不读取真实凭证或独立评测集。延续用户“暂不加入新论文”的范围；c13/c18 USTC 四次审批拒绝继续有效，不重试、不改道。

1. 保存源码、测试、现有三案例材料和 T08a/T08b/F1 历史产物哈希。以“尚无共同 HTTP 传输/准备包”的专项检查建立基线。
2. 新增基准侧 HTTP 薄适配：原样传递已审计的共同请求；不改变模型参数、提示或科学后端；限制响应体、严格 JSON/结束状态，保留自报模型与 usage；超时及服务错误不重试。
3. 将新传输的地址、配置、实现及 httpx 版本纳入会话身份；请求预留后调用，调用后保存不含密钥/错误体的结构化传输收据；旧注入接口兼容。
4. 新增纯离线准备/校验入口，冻结清单、具体来源与实验哈希、模型/预算、服务地址和实现哈希。包的状态始终是准备完成、等待明确外发决定，不生成批准记录，也不提供本轮线上执行命令。
5. 用 httpx.MockTransport 经过实际 HTTP 编解码，覆盖三工作流、原生父任务恢复、地址切换拒绝、HTTP/超时/异常/无效响应/未知 usage、限流无重试与审计。Mock 明确标为 scripted_control，不把虚拟响应归为 live_model。
6. 用既有材料和字面脚本跑 30 阶段 HTTP 模拟演练，实际科学工具执行；单元/HTTP故障/数值/真实模型表现分别记录。完成完整回归、源码差异、快照、原始日志与任务队列更新。

协议依据：复用项目已有 Chat Completions 兼容请求子集；2026-10-19 查阅 [OpenAI 官方创建接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。此兼容子集不是所有模型都接受的参数全集，未验证的服务不自动删参或切协议。
