## 修复内容

原数值正则会把 `k = 1/2` 中的 `1` 当作完整参数声明。与另一处正确的 `k = 0.5` 并存时，这会制造虚假的来源冲突；放在澄清段里，又可能用截断值错误清除真正的缺失或冲突。

现在检查数值后的完整边界：分数、加减乘除、幂、取模、算式后缀、残缺科学计数法以及直接黏连的额外字符，均不作为完整数值字面量。声明前的 Markdown 列表符号不会跳过右侧检查。完整小数、正负号、科学计数法及已支持的时间单位负指数继续识别；先前支持的显式时间单位换算链写法保持兼容。

这只收紧显式声明的识别范围，不计算分数或代数表达式。忽略算式前缀并不验证整个来源，也不等于新增了通用表达式语义门禁；语义支持仍为 unknown。单位换算链维持原有有限识别，并未实现任意链式等式的完整一致性证明。
