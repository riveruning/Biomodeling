# 来源赋值识别与引用自修

2026-10-18（北京时间）。根据已公开的冻结版诊断修复来源解析与错误分类。独立测试材料已经被读取，本轮属于开发回归；原始材料、冻结副本、模型回答和既有比较成绩保持原样。

## 行为变化

- `a + b = 0.46` 之类复合表达式不再被当作 `b = 0.46`。同类加、减、乘、除、幂、链式赋值尾项也不用于产生单参数声明或解除缺失；Markdown 列表中的直接声明仍可识别。这是限定的文本检查，没有求解代数约束。
- 已有的 author clarification 标题规则扩展到 researcher clarification/correction。标题下明确、针对具体目标的声明可覆盖该目标的旧冲突；不确定、无关的回答和单纯要求忽略冲突不能解除问题。这些都是用于当前分析的声明，语义支持仍为 unknown，不验证回答者身份或论文真实性。
- 草稿的引用缺失、引用未包含所填数值、未引用已提供的研究者补充，返回 `invalid` 交还模型修正，沿用现有总调用和草稿修订预算。重复失败会结束为 incomplete，不能带着失败草稿执行。
- 实际缺失数值、未解决来源冲突、草稿值违背明确补充数值，仍为 `awaiting_input`。缺失和引用错误共存时优先保留待澄清状态；没有降低引用校验或数值匹配要求。
