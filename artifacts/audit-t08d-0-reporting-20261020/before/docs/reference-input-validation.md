# 参考结果输入验证（2026-10-18）

## 已复现问题与修复

CLI 原先先尝试解码完整 SimulationResult，任意 SchemaError 后再按简写读取。加入 scales 等评分字段会触发回退；回退写死 succeeded，因此明确 failed 的参考结果也会被提升为成功，其他格式错误同样可能被忽略。

现在仅移除已支持的外层评分与来源描述字段（scales、threshold、schema_version、track、model_id、reference_methods、cross_method_error、limitations），其余字段全部走严格领域解码。仅缺省 status 时给简写填入 succeeded；显式失败、非法状态、错误的结构字段和未知字段均拒绝。输入字典不修改；来源描述的存在不构成验证证据。

新增统一参考输入预检：必须成功，具有非空样本与列，时间严格递增，所有数据有限。CLI、直接运行、Agent 启动与恢复均在仿真、缓存查询、模型调用或新回复写入前拒绝不可用参考。比较接口也尊重字典形式中显式提供的失败状态；旧简写不带 status 时仍可比较。

## 验证与范围

新增 33 项回归覆盖状态覆盖漏洞、格式错误、完整结果与简写兼容、错误参考的提前拒绝、旧检查点恢复和字典比较入口。完整测试共 464 项，最终结果以 artifacts/reference-input-validation-20261018/acceptance.json 和 installed-pytest.xml 为准。保存变更前后文件、补丁与测试日志。另运行三个原检查点的脚本化兼容演练，沿用原数值参考与预算；这些演练不代表自主模型能力。

这次没有调用外部模型，没有修改独立测试集，也不声称提高了完整 Agent 基准通过率。预检仅证明参考在格式上可用于比较，不证明参考来源、科学结论或数值正确性；不会修复、裁剪或转换参考数据。离线数值比较仍遵守已有显式时间单位协议。
