# 阶段审计与论文研究计划

对象：T01–T08c 后的当前工作区。审计标识：`research-readiness-audit`。
本报告新增独立文档与任务清单，不覆盖旧报告、旧成绩或产品源码。结论来自源码抽查、冻结产物核对、局部回归和相关研究原文；不是全面安全审计或独立领域认证。

## 结论与研究定位

当前已形成可审计的单 Agent 科研工程原型，具备受约束 ODE 建模、确定性计算、证据位置与目标绑定、研究者澄清、预算和受控恢复。论文准备的主要瓶颈是研究问题与证据闭环：当前版本还没有经过独立领域审核的未见真实论文对照，也没有证明关键模块带来净收益。现阶段不需要重写单 Agent 架构。

建议主线：**在材料缺失、条件冲突和澄清交互下，证据约束与可恢复执行能否降低生物动力学建模中的无依据执行，同时控制误阻断、完成率损失和人工成本？**

这是一项待检验假设，不是现有结论。先聚焦受支持的小规模确定性 ODE 文献重建；拟合与机制比较作为后续扩展。暂不主张任意论文自动复现、开放式科学发现或超过通用 Agent。面向领域方法/科研软件论文的定位更贴合当前成果；若目标是通用 Agent 方法论文，还需要更强的机制归因、跨任务泛化和相对已有方法的新贡献。

## 与已有研究的关系

- Talk2Biomodels 已支持自然语言交互、SBML/BioModels 模型、模拟、分析及论文 RAG。因此“LLM + SBML + RAG”本身不足以支撑创新主张；我们的可检验切口在于证据不足时的决策质量、澄清后的恢复和可复核的科学执行。[论文原文](https://link.springer.com/article/10.1186/s12859-025-06310-1)
- KinModGPT 已研究自然语言到动力学/SBML 模型生成；后续相关工作表应逐项比较任务输入、证据要求、缺口处理和执行验证，不能仅以缺少我方接口判竞争者失败。[论文记录](https://pmc.ncbi.nlm.nih.gov/articles/PMC10138937/)
- AI Agents That Matter 提醒区分模型与应用开发者评价、联合衡量准确性和成本，并控制评测过拟合。这里据此设计两条对照轨道与固定测试分组，不引用其成绩作为我们的目标。[原文](https://arxiv.org/abs/2407.01502)
- ScienceAgentBench 强调真实科学工作流中的可评分任务与专家验证；CORE-Bench 聚焦计算复现。这里借鉴任务级检查和可执行产物评价，不将它们的任务数或分数设成普适投稿门槛。[ScienceAgentBench](https://arxiv.org/abs/2410.05080)、[CORE-Bench](https://arxiv.org/abs/2409.11363)

以上是针对本项目的研究设计建议，不是穷尽所有截至当前的相关工作；检索相关方法论文没有向项目评测集添加新论文。

## 两条对照轨道与评分方案

**轨道S：实际产品系统比较。** BioModel Agent 对实际 Codex，候选沿用用户的 `gpt-6.1-sol` 和暂按“Atra”解释的 `gpt-6-astra`。服务配置按用户要求稍后讨论。冻结共同任务、材料、允许人工回复和输出要求；允许各自原生工作方式，披露工具、模型版本、推理设置、联网与文件可见性差异。Codex 可交付其原生程序，由外部评测器运行/评分，不能仅因没有我方SBML/JSON格式判其科学错误。必要的标准输出适配在所有运行前冻结。

**轨道F：同模型框架归因。** 固定底层模型与共同科学工具，比较固定流程、通用工具 Agent、领域 Agent；温度等参数只在确实支持时冻结，不能静默替换模型或假称所有原生设置等价。主要回答编排/约束带来的增益，不以轨道S的差异作因果解释。

两轨都报告墙钟、模型调用、工具调用、可见token、缓存和人工介入；模型费用有可核查账单/价格版本才计算，缺失为unknown。原生产品若不能统一token硬限额，使用共同墙钟及多个预算档，报告成本–正确完成–无依据执行的权衡，不声称严格等算力。初始、补齐后新会话、原会话恢复分开；回复内容预先冻结，不能按系统输出临时喂答案。

主指标预注册：

1. 有充分材料任务的正确完成率：可执行且数值通过，关键参数/方程/初值/单位与条件有审核支持；单独报告未审核、确认失败和已确认成功。不要把 `completed` 等同科学正确。
2. 不充分材料任务的无依据执行/完成率，同时报告有效拒绝、针对性追问、澄清后原任务恢复率。对充分材料的过度阻断单独计数，防止“永远拒绝”获胜。
3. 来源判定区分直接陈述、允许推导、仅在特定条件成立、未解决冲突、缺失；对合法单位换算或推导按事前规范评分，不能把所有非逐字复制都算编造。
4. 人工成本拆分一次性材料审核/配置与每任务介入次数、时间；补充最终结论的可复核性与专家复核耗时。
5. 失败按解析、检索、提案契约、证据绑定、策略决策、科学计算、服务/基础设施、评分争议分层。全部预定任务保留分母，运行中修复后另开版本，首轮失败不覆盖。

统计按论文/机制家庭配对分析，重复采样和同文多任务不能按独立样本扩充显著性。先导阶段用于估计成功率、配对差异和相关性，再按预先指定的最小有意义效应/区间精度确定正式样本量；正式报告配对差值及家庭聚类置信区间。任务太少时只作描述性诊断。未见仅指对开发过程未见，公开论文是否进过底层模型训练不能保证。
