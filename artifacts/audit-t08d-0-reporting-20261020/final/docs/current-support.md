# 当前支持范围与证据入口

更新于2026-10-20，覆盖T08d-0报告层。单个逻辑Agent、模块化单体、SBML执行载荷与确定性科学工具继续作为当前架构。功能存在、脚本演练、数值验证和真实模型效果分别记录。

| 范围 | 当前支持 | 主要限制 / 证据 |
|---|---|---|
| 文献建模 | 受支持的小规模确定性ODE，来源内参数/初值/方程、结构化草稿、SBML构建 | 声明语法有界；不保证任意论文理解，语义支持仍unknown；[T05](evidence-binding.md) |
| 数值工具 | RoadRunner模拟、有限性/收敛与参考比较、显式时间单位检查 | 数值通过不是生物学证实；通用单位推导/换算不在当前契约内 |
| PDF | 默认pypdf，可选本地锁定版本PyMuPDF，页块/bbox定位和独立表格产物 | OCR/公式识别not_run；复杂阅读顺序和表格未独立核验；[T06](pdf-parser-adapter.md) |
| 检索 | 授权来源内lexical_v1和可选passage_v2，原文偏移与预算 | 默认仍lexical_v1；18例同源已见合成开发材料，领域决定pending；[T07](retrieval-review.md) |
| 记忆/指引 | 操作者维护的有范围记忆、更正/撤回/快照失效；3项内置版本指引 | 无自动审核候选流程；无真实长期任务或模块消融优势证据；[说明](memory-and-retrieval.md) |
| 澄清与恢复 | 原任务回复、累计预算、版本冻结、持久调用、受控恢复及已返回结果认领 | 任意未知工具结果不自动重试；跨分支全局限额有限；[T03b](controlled-recovery.md) |
| 受约束研究 | 冻结反馈/前馈/基线候选，训练拟合与留出比较；新计划adaptation_study_v2 | 总科学期限默认300秒、最多600秒；v1以显式旧版执行默认兼容；不支持开放机制发现、通用可辨识性结论；[T04](study-execution-deadline.md) |
| 三工作流对照 | 实际产品领域Agent及固定/通用编排，共用工具和预算；共同HTTP传输及离线准备 | 最新演练为脚本/模拟HTTP，已见3例；不是当前版本真实模型对照；[T08b](workflow-adapters.md)、[T08c](comparison-transport.md) |
| 评价报告 | v1原评分可复算；T08d-0新增待审核/缺跑/错误分层、固定分母与未知范围 | 报告v2仍只读取v1已见合成协议；不认证审核人或模型身份；[T08d-0](evaluation-reporting.md) |
| 真实模型证据 | 历史Goodwin单例、旧冻结版Codex探索小测、已发表系统替代模型变体接入 | 尚无当前版本独立领域审核的真实论文优越性结论；[阶段审计](research-readiness-audit.md) |

历史文档保存各轮实际结果，其测试数和“下一步”仅对应当时版本。最新任务按 [研究任务清单](../tasks/research-next-phase.json) 与 [优化队列](optimization-backlog.md) 追踪。T07独立审核、T08真实对照/消融仍未结项；下一项为T08d-1离线Codex对照协议及记录接口。

既有独立评测集保持隔离；暂不新增评测论文。c13/c18 USTC材料外发拒绝仍有效。候选模型名称、离线准备包和评分报告均不是新增外发授权。
