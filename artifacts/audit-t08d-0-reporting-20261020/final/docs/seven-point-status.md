# 七个 Agent 方向的实现与缺口

本表区分已实现功能、固定流程/数值验证和真实模型能力证据。代码通过回归不等于 Agent 在未见科研任务上具有优势。

| 方向 | 当前已实现 | 主要缺口 / 下一步条件 |
|---|---|---|
| 架构 | 单个逻辑 Agent、模块化单体、受控计算进程，LLM 不决定验证是否通过 | 多 Agent 仍是待验证选项。应先用相同底层模型、相近预算做质量/成本对照，再决定是否增加角色 |
| Memory | 项目/模型/来源范围的持久记忆，更正/撤回，任务快照与恢复；本轮新增有界工作上下文、原历史留存和实际发送审计 | 尚无自动生成并审核记忆候选的流程；大规模索引、跨副本撤回同步和真实长任务行为评测未完成 |
| RAG | 授权材料内的关键词/片段检索、精确原文偏移、确定性排序和预算；T07a材料包、分组/哈希/审核门、分层评分；18例已做Codex预审并另存1处标签修订候选 | Codex预审与原标注不独立，18项正式决定仍pending；没有新增论文或改动检索算法，长陈述边界与词汇差异仍有限；embedding/重排待审核后实测 |
| Tool Use | 材料读取/检索、可选本地PyMuPDF页块/表格解析与引用定位、记忆召回、技能读取、有界目标/数值/公式绑定、模拟，以及冻结的训练拟合/留出比较 | 解析与绑定不能证明语义支持；OCR/公式识别未运行，表格和复杂阅读顺序待审核；复杂语言/单位换算仍unknown，拟合仍限已验证的profile |
| 工作流 | 追问、归属回复、暂停/恢复、版本与预算冻结、一次研究执行、持久调用记录、受控故障恢复/结果认领及本地所有者；统一研究入口与科学总期限 | 任意崩溃点自动恢复、跨分支全局费用/执行限额、较复杂的研究修改与失效传播仍有限；科学工具总期限不包含此前LLM讨论或研究者等待 |
| Skill | 固定版本的 ODE 复现、澄清复核、受约束研究指引；目录随任务模式冻结，不改变权限或科学判据 | 仍为少量内置流程；可增加有独立科学案例验收的技能，不急于通用插件市场 |
| Evaluation | 完整数值/故障回归、解析解、恢复演练；T08a共同清单/固定分母；T08b实际工作流；F1句式修复；T08c共同HTTP；T08d-0独立报告v2，区分待审核与运行错误并保留旧成绩 | 当前对照仍为脚本/内存HTTP；下一项T08d-1离线Codex协议/接入，服务配置稍后讨论；同模型归因、专家审核任务及真实消融待完成；旧短期限探针敏感性V01待定位 |

本轮选择补 Memory 的工作上下文与 Evaluation，因为之前只有持久化与续跑，而每次请求仍可能携带不断增长的全部历史。详见 [上下文预算](context-budget.md)；前两轮能力见 [记忆与检索](memory-and-retrieval.md) 和 [受约束研究工具](agent-study-tool.md)。
