# T04 执行与验收计划

用户要求Codex独立继续T04。没有使用DSH或其他Agent，也没有创建新会话、安装依赖或调用外部模型。

1. 核对T03b验收哈希一致，保存全量源码/旧测试哈希、源码与路线文档快照。最近完整基线895项通过。
2. 读取三个入口、拟合/预测、报告与恢复契约。冻结修改前v1计划的原始负载，保留生成来源与内容哈希。
3. 建立15项初始验收：7失败、8通过，复现全部拟合超时仍成功、留出预测失败未阻断、父进程拟合预检不受预算、缺少受限预测及总期限字段。
4. 实现共用完成裁决、科学期限、新版计划/旧版精确兼容、受限预测与静态拟合预检；旧命令走同一个冻结计划适配层。首轮111项通过。
5. 扩展到31项验收：同一实际计划跨三个入口、正负科学结果、预算不重置、子进程回收、超时结果认领、已存成功标志不能掩盖实际失败。扩展31项通过。
6. 执行完整回归，并独立保存同一正/负例的三个入口实际数值、极短期限的真实中断/恢复与导出闭包。最终状态、命令、数量、哈希与限制以acceptance.json为准。

限于科学研究工具的总预算；不把此前LLM讨论或研究者等待计入该预算。不宣称跨副本exactly-once、操作系统硬实时或真实模型能力提升。后续T05处理数值/公式与证据目标绑定。
