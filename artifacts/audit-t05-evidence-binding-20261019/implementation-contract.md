# T05: versioned target-to-source binding

Codex implements and validates this round independently, continuing the latest division. Preserve existing sources and tests; accepted baseline is 926 passing tests. No DSH, subagents, new dependencies, external model calls or c13/c18 material transmission.

1. Establish wrong-target/same-number, wrong-value, wrong-equation/target and cropped-expression failures; include valid literal/ODE/reaction controls and source whitelist/offset controls.
2. Add a small deterministic binding module. Inputs are a typed target descriptor from ModelDraft or actual SBML, the exact authorized source/page/span and optional explicit symbol_map. Output is a versioned record with proposed canonical value/expression, parsed declaration target/type/value/expression, original page offsets, mapping witnesses, matched/mismatch/unknown and stable reason. It is bounded text binding, never a biological semantic-support proof.
3. Parse declarations from original source context, not an isolated cropped quote. A+K=1 must not turn into K=1; K=1/2 must not turn into K=1. Respect case, initial markers, declaration boundaries, negation/uncertainty and aliases. Unsupported wording/grammar remains unknown. Limits bound quote/context length, declaration count, symbols, AST nodes and polynomial terms/powers/coefficients.
4. Formula checks use existing safe expression parsing and bounded exact symbolic normalization for simple polynomials. Do not use eval, generated code, numerical sampling or unrestricted symbolic simplification to declare equivalence. Identical supported non-polynomial ASTs may match; unproved transformations remain unknown.
5. Optional symbol_map maps source identifiers to model identifiers, one-to-one, within allowed symbols. Every rename must be explicitly stated in the cited span using supported `Symbol A maps to a` syntax. Mapping text alone is not a human approval or independent fact verification. Unsupported/unproved mappings cannot invent a match.
6. Agent submission preflights all citations/bindings before creating claims. Known mismatches and cropped/reparable citations are invalid and return targeted diagnostics for repair. Unsupported required bindings pause for clarification. Keep missing-value and source-conflict gates, citation ambiguity diagnostics, repair budgets and hypothesis conjecture authority.
7. New claims embed tool-derived binding records; raw caller-supplied support/status fields remain forbidden. Low-level source validation recomputes bindings from real source and actual SBML before cache/solver access, rechecks stored records, and rejects incompatible typed claims or wrong-target reuse. Generic old claims remain readable; citation coverage is distinct from binding coverage and semantic_support remains unknown. Low-level models with no citations retain the existing explicitly unverified numerical-diagnostic behavior.
8. Preserve T03b recovery/export and T04 scientific deadlines. Archive original failures, real repair/clarification/solver examples, all source diffs, versions and regressions. Already-seen examples remain development regressions, not a holdout capability score.
