# 历史研究产物

这里保存各轮实验、审计和演示的冻结证据。它们不参与产品安装；新的运行结果推荐保存在已忽略的 `runs/` 下。

完整 Git 仓库保留原有路径、对象哈希及失败记录。GitHub 的源代码 ZIP 和 `scripts/package_starter.py` 生成的使用包省略这里的历史子目录；需要查阅完整证据时请克隆仓库或在 GitHub 查看。

常用入口：

- [Goodwin 完整工具流程演示](https://github.com/riveruning/Biomodeling/tree/main/artifacts/literature-workflow-demo-20261021-normalized)：冻结提案、数值对照、报告、研究包和复算。
- [初版验收](https://github.com/riveruning/Biomodeling/tree/main/artifacts/v0.1)：初版科学计算与 Agent 演示记录。
- [当前能力与证据索引](../docs/current-support.md)：按功能查阅历史审计。

安装和接入服务请看[项目首页](../README.md)。新的产物默认不再进入 Git；确需发布的研究证据应显式选择并检查内容后加入。
