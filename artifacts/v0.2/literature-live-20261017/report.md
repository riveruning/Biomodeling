# 首次真实论文 Agent 试验结果

2026-10-17；模型 qwen3.8-chat，使用现有 USTC 服务。两组实际调用均已完成。

| 输入 | 实际行为 | 本次结果 |
|---|---|---|
| 原始文本 | 读取后发现方程/参数为图片占位符，主动请求方程、参数和初值 | 没有提交模型或执行模拟；没有无依据补全评分目标 |
| 辅助转录 | 提交了 8 个参数、3 条方程及来源引用；三个初值均为 null | 11/11 个可评分项目匹配；3/3 个缺失初值留空，未执行模拟 |

辅助组并非完整建模通过。第一次提交把参数单位设为 null，类型检查拒绝；第二次区室大小仍为 null，再次拒绝。第三次提交进入 awaiting_input，同时保留三个非负性/速率规则兼容性阻断。该状态不能理解为只剩初值一个问题。

逐项 11/11 仅覆盖方程、参数值及引用，不覆盖单位、区室和状态约束。最终提案仍有当前 profile 不支持的 nonnegative=true + rate rule 组合。工具没有创建可执行模型，也没有启动论文模拟。

本轮共 6 次模型调用，服务返回总 token 19,407。raw 2 次、0 次修复；assisted 4 次、2 次修复。没有独立计价依据，因此不估算费用。

结论：本次案例中，图片公式的文本可访问性是第一处障碍；补充转录后，核心内容可以正确提取，但提示词与结构化契约对未知字段和 rate-rule 约束的说明仍有缺口。建议下一步先明确 unknown 与 null 的字段规则、区室默认值的适用条件，以及 rate-rule 非负性表示，再测试人审与续跑。

原文、来源范围、输入哈希和辅助转录均固定于本轮 manifest。参考答案尚待独立人审。本次仅涉及一篇论文的指定片段及辅助材料，不能估计任意论文成功率，也没有通用助手或固定工作流的同预算优势结论。

独立数值控制仍通过，最大缩放误差 1.2165e-5；该控制使用分析者选择的初值，不是本次 Agent 提取后的论文原图复现。

机器证据：evaluation.json、live-review.json、run-configuration.json，以及两组 Agent 存储、提案和逐项分数。
