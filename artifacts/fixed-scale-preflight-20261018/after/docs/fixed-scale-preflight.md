# 固定评分尺度预检（2026-10-18）

## 真实复现

运行入口原先对 scales 中每项直接 float(value)。虽然底层比较器明确拒绝布尔值，入口却把 JSON true 变成 1.0。使用 dx/dt=-0.4x、x(0)=1 的实际求解结果与解析解参考，scales={"x": true} 得到数值比较 pass 和 passed_structured_reference。修复前后证据位于 artifacts/fixed-scale-preflight-20261018/before.json 与 after.json。

## 修改

统一 validation.validate_scales 校验调用者提供的固定尺度：字典键须为非空字符串，每个值须为正且有限的数字，布尔值和数字字符串均拒绝。通过校验的整数和浮点数复制为浮点字典，不修改调用者输入。提供参考时还要求尺度覆盖全部参考列。None 仍表示未提供固定尺度，沿用不执行参考比较的原有行为，不自动补齐缺失尺度。

直接运行和 Agent 启动在缓存查询、仿真、模型调用或任务写入前校验；恢复旧任务在研究者回复写入前校验。有效额外列尺度保留，非法额外尺度拒绝。任务和重放冻结通过校验的尺度，保持数值规则一致。底层误差公式与阈值没有修改。

## 验证

新增 24 项回归，覆盖非法类型、非正与非有限尺度、缺列、无参考输入、CLI 入口及旧检查点恢复。真实求解验证解析解匹配、错误参考失败、缓存和重放。完整回归 488 项；以 artifacts/fixed-scale-preflight-20261018/acceptance.json 与 installed-pytest.xml 为最终验收证据。另运行三个原检查点的脚本化离线演练；不把脚本操作当作模型自主能力。

未调用外部模型，未修改原始评测或独立测试集。尺度的格式有效不等于来源被证实，也不证明其科学合理性；未测得新的 Agent 基准成功率。
