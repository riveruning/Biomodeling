# 缩放误差的中间溢出（2026-10-18）

## 复现与修复

两条有限轨迹分别为 1e308 和 -1e308，固定尺度 1e308。数学上的缩放误差为 2，但原实现先计算差值而溢出为 Infinity，导致阈值为 3 时错误判失败，且比较结果无法按严格 JSON 保存。尺度为 1 时，真实误差确实超出浮点范围，同样无法序列化。

正常范围仍走原有浮点路径。仅在中间误差非有限时，使用标准库 Decimal 对原始二进制浮点值作高精度差值和除法，再转回浮点。可表示的误差继续使用原有 <= 阈值比较。真正超出浮点表示范围时，结果明确 fail，max_scaled_error=null、error_overflow=true，并保留出错列/样本；任何有限阈值都不会使该结果通过。不把误差截断为最大浮点数，不把 null 当作零。

应用记录、缓存、重放与可读报告保留溢出标记。收敛检查显示明确的溢出失败。修复前后可重复输入与输出位于 artifacts/scaled-error-overflow-20261018/before.json 与 after.json。

## 验证

新增 14 项测试，以 Python Fraction 的精确有理数计算作为可表示误差的独立核对；覆盖正负方向、恢复后的阈值边界、仅除法溢出、真正超界、收敛失败，以及记录/缓存/重放/CLI/报告的 JSON 安全性。应用边界测试使用明确标注的确定性求解器替身，不冒充真实物理模拟。其余项目真实求解回归保留。

完整测试 540 项，以 artifacts/scaled-error-overflow-20261018/acceptance.json 与 installed-pytest.xml 为最终证据；另有三个原检查点的脚本化离线兼容演练。未调用外部模型，未修改独立测试集或原始评测结论。
