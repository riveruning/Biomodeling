# 受控故障恢复与结果认领（T03b）

任务来自[优化队列](optimization-backlog.md)，建立在[T03a 调用记录](invocation-journal.md)上。新增显式恢复入口，保留单 Agent 与确定性科学工具架构。它支持有完整、兼容记录的中断执行；结果未知时停留待处置，不承诺任意崩溃都能自动继续。

## 使用

```bash
# EXECUTION_REF 指 agent_execution；不是 agent_run。
.venv/bin/python -m biomodel_agent agent-recovery-status EXECUTION_REF --store artifacts/my-agent

# 诊断就绪后，由操作者明确发起；沿用原模型、地址与生成设置。
.venv/bin/python -m biomodel_agent agent-recover EXECUTION_REF --store artifacts/my-agent \
  --base-url https://YOUR_ORIGINAL_PROVIDER/v1
```

第二条使用原 API key 环境变量，支持 `--api-key-env`；恢复不会修改冻结科学设置或调用上限。已有 `awaiting_input` 最终记录仍通过 `agent-resume` 加研究者回复，不通过故障恢复入口续跑。Python API 为 `recovery.diagnose_execution(store, execution_ref)` 和 `agent.recover_agent(store, provider, execution_ref)`。

诊断返回 `ready` / `blocked` / `finished`，以及累计调用/计算计数、稳定操作顺序、阻断原因、已绑定结果引用和既有恢复记录。CLI 只显示摘要，不重复打印完整请求与原文。`ready` 表示日志与兼容性允许重建；实际继续仍会在所有者锁内重新诊断，并检查原提供方身份、科学配置、记忆有效性及研究计划。

## 持久化与恢复规则

每次新执行保留原始初态：来源白名单、原研究者回复分支初态，以及源码、Python 和主要科学库版本的指纹。每次调用增加严格正整数 `sequence`，预留与终态共享序号；不依靠索引时间排序。原调用预算仍在执行前预留，不因恢复或错误退还。

只读诊断直接扫描不可变对象，验证哈希、引用、版本、操作配对、序号和累计预算。对象落盘后而索引尚未提交的预留也能发现。命令行诊断使用已有存储的只读视图，不初始化 SQLite、不修复索引、不写新对象或锁文件。

| 中断状态 | 恢复行为 |
|---|---|
| 模型回答已经写入 returned，但动作未处理 | 复用回答与 usage，不重发请求，不再计一次调用 |
| 草稿已返回 | 从保存的完整检查结果与真实 model 引用恢复，不再提交草稿 |
| 模拟或研究已 returned 并绑定实际结果 | 验证结果类型、原模型/草稿或计划、冻结科学输入；沿用结果引用，不重算、不重新拟合 |
| 读工具只有最后一条 reserved | 允许重新读取；沿用同一预留、操作 ID 和序号，补真实终态 |
| 外部请求只有 reserved | `external_outcome_unknown`，拒绝自动重发 |
| 计算只有 reserved，或只有无法定位的部分产物 | 拒绝继续；不通过“找最新结果”推断归属 |
| 已记录 error / interrupted | 仅异常类型不足以重建原异常处理流程，保守阻断；不推断没有副作用 |
| 已有最终 agent_run | 拒绝再次故障恢复；研究者追问使用正常恢复入口 |
| 指纹、来源范围、结果绑定、日志配对或计数不一致 | 在继续执行前拒绝 |

重建时从已冻结的初态执行原有控制逻辑，对已经返回的调用注入保存的真实返回值；不调用其 provider/工具 callback。每一步的名称和请求数据必须与记录完全一致，剩余记录未消费则拒绝完成。后续新调用仍走原预留边界。实际调用次数继承，已消费的科学执行仍只有一次。

恢复沿用原 `execution_ref`，新增 `agent_recovery` 收据，记录当时的调用集合、预算和可认领结果。收据不表示已经完成。恢复本身再次崩溃后，可继续检查同一执行；已保存的新回答也会复用。最终检查点和 agent_run 引用原调用与恢复收据，正常 bundle 导出保留闭包。

## 所有者与研究者分支

正常执行、研究者回复恢复和故障恢复，均持有同一冻结任务的本地 `flock` 所有者锁；竞争执行立即拒绝。锁覆盖 provider 和科学工具，拒绝抢占时尚未写研究者回复或恢复收据。锁文件保留，进程退出由操作系统释放，不按文件年龄或 PID 猜测租约过期，也不删除锁文件制造新锁。

研究者显式再次使用同一暂停父记录并提交回复，会创建不同执行 ID，保存父记录、归属回复和 `researcher_reply` 分支类别；原历史不覆盖。故障恢复延续已有执行，不会自动创建替代分支。预算按分支继承，尚无跨分支全局金额/token 上限。
