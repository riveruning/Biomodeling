CLI：`python -m biomodel_agent agent ... --failure-handling`，可与 `--task-planning` 同用。完整参数见 `python -m biomodel_agent agent --help`。

| 原始事实 | 确定的处理路径 | 停止条件 |
|---|---|---|
| 引文、绑定或模型结构错误 | 返回原检查，允许模型重新提交；无自动改写方程 | 累计修复/调用耗尽；重复同一失败请求；连续三轮阻塞键未减少 |
| 参数或初值缺失 | 对一个明确目标自动调用本地 `investigate_parameter`，返回原文线索 | 每目标最多一次、全任务最多四次自动查证；无调用余额、计划阻断或仍有明确来源问题则追问 |
| 来源冲突、单位或条件问题 | 保存原始诊断与引用，形成目标明确的研究者问题 | 暂停等待归属明确的回复，不静默选值或换算 |
| 数值检查或参考比较失败 | 决策产物引用实际 run 及其检查，停止本任务 | 不再科学计算，不修改阈值、参考或求解设置 |
| 科学工具异常，没有确认返回 | 保存异常与“结果未确认”的诊断，停止 | 未知计算效果不当作未执行，不自动重试 |
| 临时服务问题 | 完全沿用既有 ProviderError 重试策略 | 原 max_retries、max_calls、不可重试标记及延期规则保持有效 |
| 未分类工具错误 | 保守停止；无自动工具重试 | 操作者检查原始诊断后决定下一步 |

本地查证不会联网、导入新来源、估值或采用参数。关键词命中仍可能只是公式里的符号；没有显式冲突也不表示存在数值声明。这类线索交给模型检查，仍需重新提交有依据的草稿或追问。明确没有线索、明确来源问题或检索异常时，系统直接形成追问。自动次数限制独立于模型主动提出的检索，后者受 provider 调用和可选计划步骤预算约束。

每次路由保存不可变 `failure_decision`：冻结策略、触发事件、来源范围、原始反馈、请求摘要、阻塞键、累计预算和决定。原始草稿提议、检索内容、数值检查仍独立保存。重复失败识别使用动作、完整参数和当前来源范围的摘要；计划阻断尚未调用工具，允许依赖满足后重新检查。修改无关措辞不会清空阻塞键统计。阻塞键由类别、检查码和目标构成；它只是有限的工程停机启发式，可能保守阻断，不能据此宣称修复质量。有效草稿开始新的错误窗口；研究者回复更新来源窗口，但不退还调用、修复或查证次数。

所有真实调用仍通过原 journal。已返回的路由和查证结果在恢复时核对产物、请求和冻结策略后认领；没有返回收据的写入保持阻断。自动查证也经过 R04 计划依赖/次数检查，并作为实际查证步骤计数。进度、检查点、报告和可导出对象闭包包含路由记录；上下文压缩保留最新路由。
