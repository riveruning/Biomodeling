# R07：有工具依赖与产物检查的科研流程

2026-10-25。新增三项只读科研流程契约，显式启用 `run_agent(..., scientific_skills=True)` 或 `python -m biomodel_agent agent ... --scientific-skills`。旧指引和默认任务入口保留，当前新流程仅支持 ODE reproduction。

| 流程 | 必要输入/依赖 | 原始工具与产物 | 只读检查与停止条件 |
|---|---|---|---|
| parameter_adoption_v1 | 冻结的参数单位/条件要求、授权来源 | investigate_parameter、inspect_source、assess_parameter、submit_draft；assessment、draft、model | 从实际草稿引用重算评估；当前来源、值、单位、时钟与要求一致且模型就绪才 pass。缺失/冲突保持 blocked，来源变更后必须重检 |
| reference_comparison_v1 | 内部冻结参考、固定尺度、已引用模型 | submit_draft、run、inspect_progress；实际 run 和 simulation_input | 核对当前模型、冻结实验/求解器/数据/参考/尺度，以及 strict 与阈值；读取实际比较和数值裁决。失败停止，不能调阈值、换参考或重跑 |
| failure_diagnosis_v1 | 已启用 R05 的冻结 failure_policy、实际错误 | 原始诊断、route_failure 决策产物、inspect_progress | 重算已保存决策，显示 recorded 和实际路由；这不代表修复成功。冲突追问、重复/无进展/预算耗尽停止，未知效果不重试 |

每项契约包含版本、适用目的、输入、工具依赖、步骤、预期产物、验收和停止条件。任务创建时将契约存为不可变 scientific_skill 对象并冻结引用；缺少输入或工具时不进入可加载目录。`inspect_progress` 可查看 availability 中的缺失原因。未接通的估参和 FBA 没有开放新流程，也没有增加执行工具。

通过已有 `load_skill(name=...)` 按需读取契约。加载只提供流程；没有实际草稿、评估、运行或失败决策时，状态是 not_run。进度和最终报告的 scientific_skills 来自工具实际保存的对象，不接受模型自填的完成标记。pass 只表示相应工程检查通过；所有新流程的 scientific_support 保持 unknown。流程没有独立科学审核权，也不会改变原提交、数值检查或终止裁决。

参考值仍保持内部冻结，不将参考序列写入指引或任务初始提示。流程检查返回状态及产物引用；不把评价参考转为供模型拟合的输入。参数流程会重新读取原材料和评估声明；声明一致不是生物学适用性的证明。

每份加载响应最多4000字符；压缩上下文保留每个已加载新流程的最新指引。超过既有总上下文上限时明确停止，不静默截断必需规则。4000字符的单项上限不保证三项同时加载可放进最小8000字符任务预算；可按任务需要加载并配置原有总预算。模型主动加载仍消耗原 provider 调用预算，实际工具保留原预算、来源限制与冻结研究边界。

已返回的加载结果在恢复时核对冻结契约、请求和返回内容，伪造内容会阻断；新契约随对象闭包导出，脱离原store仍可重建相同进度。研究者回复不会开放新能力或退还调用；旧参数评估跨来源变更变为 blocked。

演练与完整回归见 [R07 交付记录](../artifacts/r07-scientific-skills-20261025/README.md)。最终完整回归1682项通过，其中新增27项；8例固定脚本演练与45对象闭包进度重建通过。既有开发用例分别覆盖三项流程，以及缺条件、错误参考、重复失败、暂停恢复、上下文超限、伪造返回和协议放宽负控制。有/无指引使用相同固定脚本时可检查工具结果与额外调用成本，不能衡量真实模型的决策收益。真实有/无 Skill 对照和领域审核仍待完成，不用流程数量或文档长度当作科研能力成绩。
