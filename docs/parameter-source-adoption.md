# 原生参数记录到模型采用：R01

2026-10-25。本轮补齐 SABIO-RK 已导入原生记录的参数整理、显式换算、条件核对、提交检查和来源追踪。复用原有 `assess_parameter`、模型绑定和严格数值执行流程。

## 实际流程

1. 使用已有 `knowledge-search`/`knowledge-fetch` 搜索并导入数据库记录，保存原始响应与请求收据。
2. 在启动新任务前，明确选择原始 `kineticlaw.parameter` 数组下标、模型目标和目标单位，生成派生来源。
3. 调用者明确冻结参数单位、反应、参数类型和所需实验条件，把原始及派生来源加入新任务。
4. Agent 用 `assess_parameter` 核对，提交草稿时附 assessment 和派生数值声明的准确引用。
5. 提交前重算原生字段及转换结果；执行时通过引用检查再次验证派生来源。通过后才生成模型并运行。

```bash
.venv/bin/python -m biomodel_agent parameter-source ORIGINAL_SOURCE_REF \
  --store artifacts/my-task --target kcat/value --parameter-index 0 --unit second^-1
```

这里的下标是原始参数数组的下标，包括其中的 Variable 项，不是搜索摘要中筛选后的序号。命令返回新的 `source_ref`、派生说明与可引用文本；不会联网，也不会把来源偷偷加入正在运行的冻结任务。

这一步替代人工逐行转录标签，不需要手写参数声明。目标映射仍由操作者明确选择；程序无法仅凭 `k` 这个模型符号判断它应当对应 `kcat` 还是 `Km`。

## 参数与条件的检查

读取原始数值和单位，而不直接采用数据库给出的 normalized value。每次转换保存原值、原单位、整数分子/分母、计算规则和结果。如果提供了受支持的 normalized 单位，还会检查数据库规范值与重算是否一致。

来源记录同时保留原生参数名、数组位置、反应、参数类型、物种、温度、pH、缓冲液、酶名称/变体、实验类型、组织/菌株及所涉物种标识等已有字段和 JSON 路径。不会推断缺失值，也不会把底物特异的参数泛化为任意物种的参数。

采用原生参数时，冻结 requirements 必须明确列出提取到的条件；物种、反应和 quantity_kind 即使原记录缺失，也必须得到明确补充才可能通过。已知酶变体不能被省略。缺少要求或原生字段为 `unknown`，明确不同为 `mismatch`。这些检查只比较显式字段，不认证实验或科学适用性。

示意 requirements（条件值必须来自实际任务需求，不能为了通过检查照抄来源）：

```json
{
  "k/value": {
    "unit": "second^-1",
    "conditions": {
      "organism": "synthetic-system",
      "reaction": "X = Y",
      "quantity_kind": "first_order_rate",
      "experiment_type": "synthetic_fixture",
      "temperature_c": 25,
      "pH": 7
    }
  }
}
```

不同明确条件的派生来源作为不同候选：冻结要求排除的候选写进 assessment 的 `context_exclusions`，不把不同温度下的值一律视为冲突。相同条件下仍有不一致数值时继续阻断；未明确条件的来源不因“看起来相似”而自动排除。普通自然语言来源仍沿用保守的冲突检查，不新增复杂条件块的语义理解。

## 显式单位换算及边界

支持有限的时间、反时间、浓度、物质量和无量纲单位及列明别名，包括 SABIO-RK 的 `min^(-1)`、`s^(-1)`。例如：

- `7200 min^(-1) × 1/60 = 120 second^-1`。
- `1.02 mM × 1/1000 = 0.00102 M`。

换算不自动应用到未经选择的参数。未知复合单位、浓度与物质量之间缺体积的转换、非有限数、溢出/下溢、原始数值或条件区间、未支持的其他环境变量都拒绝。执行端仍需支持目标单位，反时间参数必须与模型时钟一致。

派生来源不是新测量值。引用标为 `model_inference` / `derived_from`；参数来源保留 `database_reported`。原生原文、请求响应、字段路径和换算见证均可追溯。重新保存过但内容被改写的派生来源不能靠新哈希获得通过，核对器会从原记录重新计算。
