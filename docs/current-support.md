2026-10-30 前一增量：[本地研究工作台](research-workbench.md)已接入任务/输入修订、六类建议与原文核对、显式采纳、异步执行、原任务回答/恢复、报告和结果包下载；默认不调用模型服务。57 项专项控制和源码/安装版回环 HTTP 演练通过，真实浏览器完成离线及脚本化完整流程；最终全量结果见本批验收，不能作为线上模型效果。

2026-10-30 前一增量：[类型建议与输入草稿](task-proposals.md)覆盖六类既有工作流，保留理由、原文锚点和未知项，显式选择后生成任务修订；有限完整文本布尔声明可经逐项核对生成原生模型。建议调用有独立 opt-in 预算和返回认领，线上效果尚未验证；并非自然语言规则推断或任意论文到模型。

2026-10-30 前一增量：[统一科研任务入口与六类续接](research-tasks.md)已实现输入缺口、六类显式分派、共同状态/报告与受控续接；新增四类 opt-in typed v2 的暂停/恢复。该增量当时尚未接通建议层；最新范围见上段。

更新于2026-10-27，R09新增[FBA Agent暂停与受控恢复](fba-recovery.md)。用户随后要求把清单其余类型全补入，本轮新增[随机、PDE、布尔、个体四类原生执行架构](model-types.md)；R02后续暂缓。单个逻辑Agent、模块化单体和按类型的权威执行载荷继续作为当前架构。当前优先搭架构，后续用不同模型/机制家庭评价效果；Goodwin仅作已有开发案例，测试项数不表示整体科研能力。
