# 研究查询与 Windows 作业交付优化验收

2026-10-31。在开发检查点 `658eb8b` 后继续优化；使用范围和样例测量见[实现说明](../../query-read-performance.md)。科研决策协议与六类数值后端保持原语义。

## 本轮行为

- 项目面板、总览和报告在一次查询内复用已核验字节，成功返回前再核对全部由该视图观察的文件；不跨请求缓存、不以 SQLite 决定预算。
- 界面导入按输入字符串的 UTF-8 字节原样保存，保留 LF、CRLF、混合换行及 Unicode 引用位置。
- 作业的完成状态必须有已核对结束回执；读取活动状态与扫描回执的交错不能产生缺结果的完成状态。
- 被拒绝 POST 先返回原403，再对长度明确且有限的正文作有界清理；总截止0.25秒，读取窗口64KiB，不解析正文或生成业务记录。
- 界面在当前作业结束回执确认前禁用导出；轮询早于POST确认时，不访问已删除的待办项。未知效果保留原标识，不自动重发。

## 诊断与证据口径

保存了最初的Windows Unicode偏移失败、HTTP连接中止、两个稳定复现的作业完成竞争，以及真实浏览器过早导出失败。中途发现问题后中断的完整运行分别保留，均不作最终全量通过结果；原有安全/来源/预算断言未放宽。私有安装检查曾用过短作业ID，改用UUID后通过，未更改产品ID规则。

Windows性能探针只读使用未改动的既有运行包和记录，辅助器源码哈希另存，不改签原记录。最终源码及安装演练都使用新存储。不同系统和版本指纹独立保留，不能跨版本认领旧科学任务。

本轮模型响应全部为脚本，新增外部模型请求为0，独立评价集保持隔离，真实论文复现数仍为0。读取与交付改善不代表真实LLM研究判断、证据充分性或token收益已被证明。后续主线是小批真实开发文献试跑和经验候选验证。

原始记录在本地 `artifacts/read-performance-20261031/`，不随纯运行分支分发。

私有确定性浏览器包装器另发现缺少Windows多进程 `__main__` 保护，科学子进程导入时重复启动测试服务并报目录已存在。该问题只修改私有包装脚本，以全新目录/端口重验，不改产品科学状态或忽略子进程失败；原日志另存。
