## 历史研究记录

[历史首页](history.md)保留原先按日期排列的进展和原始设计入口；[阶段审计](research-readiness-audit.md)记录研究证据缺口。这些文档中的测试数、旧环境命令和待办仅对应其记录版本。

历史产物集中在 [`artifacts/`](../artifacts/README.md)，完整证据、内部任务和讨论记录仅保留在完整 Git 仓库，精简 ZIP 不含这些目录。若专题文档链接到省略的实验文件，可在 [GitHub 完整仓库](https://github.com/riveruning/Biomodeling)按同一路径查阅。安装和运行产品不需要它们。
