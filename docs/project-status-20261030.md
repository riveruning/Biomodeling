# 整体项目进度与下一阶段

最新开发增量是 [Agent 研究项目与论文开发流水线](agent-research-projects.md)。人在项目层提供应用场景与约束，Agent 负责对象、粒度、检索、证据、假设、建模和后续迭代；关键问题用具名讨论对齐。每轮保留模型、实验、判据和结果。开发批次分别统计案例、声明的论文标识、材料与家族，汇总缺口并形成未激活经验候选。

本轮验证以有界工具协议和真实后端计算为主，模型回答仍为脚本；尚未开展大量真实论文的在线自主复现。以下前序后端/工作台验收数量各有对应版本，不能与本轮结果相加作为独立科研成绩。

核对日期：2026-10-30；本批开发始于 2026-10-29。本页在[上一阶段盘点](project-status-20261028.md)基础上更新整体进度。当前仍是科研原型：六类有限计算后端已经建立，ODE 建模主线可运行，统一任务管理、六类建议与输入草稿已接通，有限来源布尔与 SSA 模型路径，本地研究工作台第一版已接通；跨类型自主建模和科研验证尚待完成。

## 后续开发主线

研究循环与开发队列已具备工程入口；下一阶段先用小批真实开发材料检验选型、证据、数据读取、构建与迭代，再根据失败分布扩展能力。

1. **真实资料端到端试用与效果验证。** 固定服务、输入、工具和预算，分开评价解析、选型、构建、执行、人工确认及 token 成本。当前工作台演练仍是合成材料和脚本响应，线上效果未知。
2. **按试用反馈迭代工作台与宿主接口。** 进一步完善输入编辑、数值图、长任务状态与标准工具适配；再评估跨类型检索、记忆和科研指引的增益。

已有独立评价集继续隔离，历史产物与源码指纹保留，DSH 写入故障没有绕过。前序整理基线已上传 GitHub，研究项目增量已随 Windows 纯运行版提交到同学仓库（PR #3）；工作区版本以源码摘要与对应验收记录为依据。
