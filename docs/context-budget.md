# 工作上下文预算与完整历史留存

长期记忆回答“跨任务保存什么”，工作上下文回答“本次模型调用带上什么”。本轮补齐后者，并增加独立的离线保留率评测。产品仍采用单 Agent，不增加依赖或摘要模型调用。

## 实际行为

新任务默认冻结 60000 个消息 JSON 字符的上下文预算。历史不超过预算时，消息原样发送；超过时，系统选择完整消息形成一个新的请求包，完整历史继续保存于检查点，不覆盖、不删改科学内容。

必须原样保留：

- 原系统指令与初始任务（含来源白名单、模式、冻结研究概要）。
- 所有带归属的 researcher_reply，包括待回答问题、回答者、来源和原文。
- 最近一次提交草稿的动作及最新草稿验证反馈。
- 最新模拟/研究反馈，以及最新成功返回的模拟/研究事实，避免后续重复调用报错覆盖原结果。
- 最新一条消息。

剩余空间按从近到远的顺序补充完整旧消息。不改写方程、参数、引文或研究者决定，也不使用 LLM 生成可能改变语义的摘要。请求中的 context_notice 仅说明旧消息被省略、完整记录仍在，以及需要时应重新读取授权材料；它不是新科学证据。

这一规则不是“所有旧信息永远在模型窗口里”的保证。旧材料片段、历史技能指引或建议性记忆可能被省略；Agent 可能需要重新读取，从而消耗已有动作预算。能否改善真实模型的完成率与成本仍须单独评测。

## 拦截与恢复

必须保留的信息自身超预算时，返回 context_budget_exceeded，任务 incomplete，保存真实诊断和完整历史，不调用下一次模型、不增加调用计数，也不自动扩大冻结预算。

恢复暂停任务时，先用与实际回复相同的消息构造器做容量预检。若新的研究者回复使必需上下文放不下，在保存回复对象、blob 或调用模型前拒绝。通过预检则沿用原预算、来源与累计调用次数。

没有 context_policy 字段（或为 None）的旧检查点沿用 legacy_full_history，不偷偷改变历史评测协议。新任务不提供关闭检查的入口；需要更大上下文可在创建时显式设置，不能通过恢复改变原预算。

## 使用与审计

```bash
.venv/bin/python -m biomodel_agent agent --store artifacts/my-study \
  --source paper.txt --experiment experiment.json --context-max-chars 60000
```

支持 8000–500000 的整数；Python API 为 run_agent(..., context_max_chars=60000)。该参数也适用于绑定 study plan 的任务。

**这里是消息数组按固定 JSON 编码计算的字符预算，不是 token 数、字节数或供应商的完整上下文窗口。** 模型输出额度、请求其他字段和服务协议开销不在此计数内；不同语言的 token/字符关系也不同。

每次成功调用和提供方错误记录实际发送的 requests、原始/发送字符数、是否压缩及省略数量。报告显示发生压缩的调用和容量拦截。完整 messages 保留在检查点，实际请求包单独记录；不能把未发送的完整历史写成模型已看到的内容。

## 验证

新增 29 项回归覆盖预算与消息协议、原文不变、Unicode、研究者更正、未解决目标、草稿/验证/已执行结果保留、嵌入伪指令、必需信息超限、恢复前无写入、传输重试审计、旧检查点兼容，以及一次长工具历史后执行真实 ODE 的闭环。恢复后的真实求解与解析衰减解继续核对，模型调用和修订预算未扩大。

另有独立输出检查器，在固定合成历史上比较 full_history 与 bounded_context_v1：

| 场景 | 完整历史 JSON 字符 | 有界请求字符 | 必须信息 |
|---|---:|---:|---|
| 短任务 | 364 | 364 | 3/3 |
| 长材料历史 | 140243 | 10624 | 4/4 |
| 部分回答与更正 | 140751 | 11132 | 6/6 |
| 已评测研究与重复调用报错 | 140276 | 10657 | 5/5 |
| 必需内容本身超限 | 9329 | 0（拒绝发送） | 正确阻断 |

三个长场景的消息字符减少约 92%，指定必须信息全部原样保留。负控制故意删除一条更正或改写科学陈述，检查器均检出。冻结输入、哈希、逐场景结果和报告位于 artifacts/context-budget-development/retention-evaluation/。

这些是固定合成输入上的精确保留与字符量测量，不是模型推理、计费或实际 token 节省的成绩。没有修改独立案例集，也未调用此前等待授权的外部模型评测。
