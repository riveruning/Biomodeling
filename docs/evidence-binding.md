# T05：结构化证据目标绑定

T05 修复了“引文中存在同一个数值，却属于其他目标”和“公式引文与模型表达式不同仍被接受”的缺口。新增有界的确定性检查；不改变单 Agent、SBML 权威执行载荷和不可变来源记录。

## 支持范围

参数、初值、ODE 右侧、反应速率和派生赋值分别建立绑定。例如 `Parameter k = 0.4` 只能支持 `k/value`，`Initial k = 0.4` 不支持参数值；`Equation dx/dt = -k*x*x` 不支持 `rule:x/expression = -k*x`。

首版识别直接声明，包括 `Initial x = 1`、`x initial 1`、`x(0) = 1`、`Parameter k = 0.4`、`k value 0.4`、`dx/dt = -k*x`、`Derived y = 2*x` 和具名反应速率。反应绑定只检查速率目标和表达式，不验证化学计量或生物学解释。

T08b-F1 增加两种固定 ODE 声明：`The intended equation is dx/dt = -k*x` 和 `The author confirms the intended equation is dx/dt = -k*x`。声明关键词大小写及词间空格可变，符号仍区分大小写。只从完整分句起点匹配，不搜索藏在任意散文中的公式；整个确认前缀包含在声明偏移内，引用裸公式或去掉作者确认前缀会被视为截短声明。

这两种句式仍使用原有左侧目标和受限表达式检查。前置的 Maybe、否定、条件等不被剥离，右侧的条件、不确定文字也不能作为公式通过。未支持的文本保留 unknown，已有错误目标等规则可能返回 mismatch；都不能成为匹配。跨句否定/作用域和语义真伪仍需审核，固定句式不是一般自然语言理解。

数字按原始十进制字面量精确比较；公式复用受限 AST 解析器，以有界多项式规范化证明简单等价，例如 `-x*k` 与 `-k*x`、`k*(x+1)` 与 `k*x+k`。不会用数值采样证明公式等价。相同的受支持函数语法可以匹配；无法证明的一般恒等式保留 unknown。

可选 `symbol_map` 的方向为“来源符号 → 草稿符号”。每一项都需要同一引文内的显式声明，例如：

```text
Symbol X maps to x; Symbol a maps to k; Equation dX/dt = -a*X.
```

仅在请求中填写 `{"X":"x","a":"k"}` 不构成证据。重复目标、冲突映射、保留符号和合并不同来源符号均不能制造匹配。映射文本本身也不是研究者批准或独立事实核验。

## 记录和执行边界

新增 claim 内嵌 `binding.version = 1`，保存目标、规范化拟议值/表达式、解析出的声明类型/符号/右侧、原文偏移、映射见证、状态和原因。原始 source/page/start/end 与 quote 保留。绑定状态与 `review_status` 独立，工具不自动升级人工审核状态。

F1 沿用相同的记录结构和 version 1，并不让旧声明自动获批。执行时仍从原文与实际 SBML 重新计算；产品实现指纹随语法代码变化，旧冻结清单和不兼容恢复快照继续拒绝。比较运行必须另存新清单，不能修改旧指纹绕过检查。

| 结果 | Agent 行为 |
|---|---|
| matched | 所有必需目标均满足时允许继续静态校验 |
| mismatch | 返回具体目标与原文位置，在原修复预算内要求模型修正 |
| unknown | 暂停并请求澄清；不会将不支持的语法当成匹配 |

草稿缺少数值和来源冲突仍优先走原有追问流程。引文歧义仍返回原有限位置候选。必需绑定预检失败时不创建部分 claim 或模型。研究者补充的公式通过原暂停恢复流程进入独立的归属来源，claim 类型仍为 human_convention。

执行入口从实际 SBML 重新读取参数、初值和公式，重新解析真实来源并比较保存的绑定；严格模式在写 simulation_input、查询缓存或调用求解器之前拒绝不匹配或未知的已提供必需证据。手工拼装模型、跨目标复用绑定、修改状态或版本均不能绕过。

旧的通用 claim 仍可读取，普通 `validate_links` 仍只报告引文覆盖。进入类型化执行检查时会重新计算其支持关系。无引文的底层数值诊断保持原有行为，缺失的绑定覆盖保持 unknown，不能因此获得论文复现通过。新绑定在导出包中随 claim 保留，T03b 结果认领不重复创建 claim 或求解。

## 预算与限制

每条引文最多 8000 字符，前后各最多检查 256 字符的声明上下文；最多 64 段声明、32 个映射。窗口截断了声明边界时保留 unknown，不能仅靠截短引文隐藏前后运算。公式仍受现有 4096 字符/512 AST 节点限制；规范化最多 128 项、64 次总次数、单次整数幂 8、系数 4096 位。数值字面量限长，避免巨大指数和嵌套幂造成无界展开。

这是直接文本声明的有界检查。复杂自然语言、一般公式变换、单位换算、中文/LaTeX 公式、跨页解释和图像公式尚未支持；遇到这些情况可能需要人工澄清。声明之外的否定、限定及跨句语义不构成已验证范围。

**matched 不会把 semantic_support 从 unknown 升级，也不证明单位正确、原文真实、模型忠实于整篇论文或生物学结论成立。** 科学运行仍单独记录数值验证和 scientific_status。
